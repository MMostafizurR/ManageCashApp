# 💰 Python & Django Cash & Expense Management App

A full-stack web application built using **Python and Django** to help users track cash flow, record income and expenses, and monitor financial balances efficiently. This project focuses on handling financial calculations, database aggregates, and user-specific transaction histories.

---

## ✨ Key Features

* **User Authentication & Private Ledgers:** Secure registration and login ensuring every user's financial records and transaction history remain completely private.
* **Income & Expense Tracking:** Add, categorize, edit, and delete cash transactions with details such as amount, date, description, and category.
* **Financial Dashboard:** Real-time overview summarizing total income, total expenses, and net cash balance.
* **Filtering & Categorization:** Organize transactions by categories or date ranges to easily monitor spending habits.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django (MVT Architecture)
* **Database:** SQLite (Default Django DB)
* **Frontend:** HTML5, CSS3, Bootstrap (for clean financial tables and forms)
* **Authentication:** Django Built-in Auth & Session Management
